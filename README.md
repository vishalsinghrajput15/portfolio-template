# Python Portfolio Template

[![Python CI](https://github.com/vishalsinghrajput15/portfolio-template/actions/workflows/ci.yml/badge.svg)](https://github.com/vishalsinghrajput15/portfolio-template/actions/workflows/ci.yml)

A reusable Python project template with automated testing
and code quality checks.

## Features

- Clean Python project structure
- Automated testing with pytest
- Code quality checks with Ruff
- GitHub Actions continuous integration
- Virtual environment support
